## 一、品质判定公式【源码】

每条鱼的品质由**加权随机**决定，权重公式：

```
有效权重 = 基础权重 × (1 + 幸运/100 × 幸运敏感度) × 天气修正
品质概率 = 该品质有效权重 ÷ 全部品质有效权重之和
```

各品质参数：

| 品质 | 基础权重 | 幸运敏感度 | 经验倍率 | 基准价 | 每阶加价 |
|---|---|---|---|---|---|
| 普通 | 550,000,000 | 0 | ×1.05 | 25 | 3 |
| 罕见 | 280,000,000 | 0.02 | ×1.15 | 60 | 5 |
| 精良 | 120,000,000 | 0.05 | ×1.30 | 150 | 15 |
| 稀有 | 40,000,000 | 0.10 | ×1.50 | 400 | 50 |
| 史诗 | 9,881,800 | 0.25 | ×1.80 | 1,000 | 200 |
| 传说 | 100,000 | 1.70 | ×2.20 | 5,000 | 1,500 |
| 神话 | 16,000 | 1.70 | ×2.80 | 70,000 | 5,000 |
| 奇异 | 2,000 | 1.50 | ×3.60 | 200,000 | 20,000 |
| 奥秘 | 200 | 2.00 | ×5.00 | 1,000,000 | 100,000 |

**关键结论**：
- 幸运敏感度是「每次 +100 幸运让该品质权重放大敏感度比例」。例：幸运 10,000 时传说权重 = 10万×(1+100×1.7)=171 万
- **普通鱼幸运敏感度为 0**——堆幸运不会增加普通，只会把普通「挤掉」并放大高阶，这就是堆运气的意义
- 天气修正如雷暴对传说/神话/奇异 ×1.25，金风对普通/罕见 ×1.25（增概率）

**实测验证**（13,261 杆，幸运 10,708 + 顶级饵 1,000）：

|---|---|
| 普通 | 35.0% |

## 二、鱼价公式【源码】

```
单条鱼出售价 = 基准价 + 阶价 × 品质内序号 + 基准价 × 地图序号 × 5%
```

- 品质内序号：同品质第 1 条 +0、第 2 条 +1 档……（每条鱼售价递增）
- 地图序号：月落溪谷=0、雾语湿地=1……星渊圣海=14，越靠后越贵
- 例：霞栖湖原(序号5)史诗第4条 = 1000 + 200×3 + 1000×5×5% = **1,850**

## 三、直接金币公式【源码】

一杆的「直接金币」是一个区间，取区间内随机：

```
智力加成 = ⌊智力 ÷ 150⌋ × 5        → 计入上限
耐力加成 = ⌊耐力 ÷ 150⌋ × 5        → 计入下限
下限 = 50(图基础) + 耐力加成 + 天赋「稳定收益II」
上限 = max(下限, 100(图基础) + 智力加成 + 天赋「稳定收益I」)
金风时：下限 += 300 + 天赋「金风感知II」
        上限 += 500 + 智力加成 + 天赋「金风感知I」
最终 = ⌊区间值 × (1 + 地图专精金币加成 ÷ 10000)⌋
```

**解读**：
- 每 150 点智力/耐力 = +5 金币；天赋直接加固定值
- **智力堆的是上限、耐力堆的是下限**；两档取 max，所以偏科也有保底
- 金风 = 直接 +300~500 区间，配合金风感知天赋（每级 +300/+100）是翻倍收益
- 实测：Lv.4217 玩家智力 7,999 / 耐力 463 → 上限 = 100+⌊7999/150⌋×5 = 365，下限 = 50+⌊463/150⌋×5 = 65，与实测单杆 168~365 金币吻合

## 四、经验公式【源码 + 实测】

经验结算在服务端，前端已确认加成乘区结构：

```
单杆经验 = 基础经验 × 品质经验倍率 × (1 + 全部加成bp ÷ 10000) × 组队船乘区
```

**经验加成来源（bp，10000 = 100%）**：

| 来源 | 数值 | 说明 |
|---|---|---|
| 智力 | 1 点 = 1bp | 上限 50,000bp（+500%）【源码】 |
| 天气 | 晴0 / 雨500 / 强风1000 / 雾2000 / 热浪3000 / 雷暴5000 / 枯潮-5000 / 奥秘涌流7500 | 【源码】 |
| 地图专精 | 固定 350~900bp + 专精等级 | 【实测】 |
| 天赋 | 渊博垂钓者每级 +500bp（+5%） | 【源码】 |
| 公会图腾 | 按图腾等级（实测 6 级 = +600bp） | 【实测】 |
| 公会区域增益 | +5000bp（+50%） | 【实测】 |
| buff | 个人/全服经验 buff（实测「万流共鸣」全服 +5000bp） | 【实测】 |
| 组队船 | 独立乘区，6 人 = +25% | 【实测】 |

**实测反推**：Lv.4217、顶级饵、热浪(+30%)+专精(+8.5%)+公会图腾(+6%)+公会区域(+50%)+万流共鸣(+50%)，单杆普通批量约 **11 万~20 万经验**，平均每杆 5.87 条鱼。
**基础经验随等级增长【未公开】**，服务端结算，当前无法给出精确公式。

**冲级结论**：雷暴/热浪天气 + 公会区域(+50%) + 全服万流共鸣(+50%) + 组队船(+25%) 是四条独立大乘区，全开时经验约为基础档 4~5 倍。

## 七、鱼饵 / 鱼竿数值速查【源码】

**鱼饵**（全图共用库存）：基础0/低级40/中级100/高级200/顶级1000。鱼饵只加幸运与品质池，顶级饵 = 至少罕见 + 幸运1000 + 神话/奇异/奥秘权重×1.5。

**鱼竿**：
- 单属性竿每级 +20 属性，双属性竿各半
- 强化成本递增，升到 500 级（上限）累计成本巨大（单竿升 499 级 ≈ 6 亿金币）
- 属性收益对比：349 级竿 = +5,235 属性 ≈ 每杆金币 +175、经验 +52%；地图固定专精 900bp = +9%——**鱼竿是中期最大单项**

## 八、四维属性性价比排序（分流派依据）

| 属性 | 定位 | 核心收益 | 适合流派 |
|---|---|---|---|
| **智力** | 万金油 | 经验 1:1、金币上限 150:5 | 冲级党、均衡 |
| **运气** | 概率引擎 | 放大高阶品质（敏感度最高的是传说以上） | 打宝党、追求神秘/奥秘 |
| **力量** | 数量引擎 | 每杆普通鱼数量、金币下限 | 批量挂机、金币党 |
| **耐力** | 续航 | 批次杆数 ×2、金币下限 | 挂机时长优先 |

**前期（Lv.<500）**：地图少且专精加成低，经验主要靠智力+天气，建议「智力竿」优先，快速冲到前四张图。
**中期（Lv.500~2000）**：鱼竿等级收益最大，主升一条属性竿到 200+ 级；天气全开冲级，金风赚钱。
**后期（Lv.>2000）**：公会区域(+50%)、组队船(+25%)、专精、天赋全部点满后，收益结构转向「运气拼高阶 + 全乘区叠加」；追传说/神话/奥秘靠运气的敏感度放大。

## 九、给后续攻略的数值结论

1. **经验第一来源是乘区叠加**（天气×公会×组队×buff），同等级下可差 4~5 倍
2. **金币第一来源是鱼价与直接金币**：高等级图鱼价高，但直接金币的天赋/金风加成是固定值，后期占比下降——所以后期「图等级」比「天赋」重要
3. **运气是唯一能突破普通鱼海的手段**，但敏感度在高阶才显著，前期堆智力性价比更高
4. **专精是慢变量**：日常多攒对应品质的鱼喂专精，长期收益是免费的永久加成
5. 每个阶段的「最优地图 + 最优鱼饵 + 最优属性侧重」将在后续分阶段攻略中给出
