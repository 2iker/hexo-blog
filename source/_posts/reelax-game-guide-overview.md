# Reelax 钓鱼游戏 · 玩法总览

> 版本：游戏内容版本 **2026.18**（数据于 2026-08-16 实站抓取，含官方前端源码与真实接口数据）。
> 说明：本文讲「游戏是什么、有哪些系统、怎么串起来」，数值细节见姊妹篇《数值体系全解》。

## 一、一句话概括

这是一款**全自动钓鱼挂机游戏**：你把鱼竿架好、选好图，游戏自动每 6 秒抛一杆并结算鱼获，产出的**金币**和**经验**支撑你解锁更高级地图、强化鱼竿、点天赋、加公会，形成越钓越快的滚雪球。

核心一句话：**等级决定你能去的图，图决定基础收益，装备/专精/天赋/buff 决定加成，加成就决定每杆产出。**

## 二、核心循环

```
选择地图(15张) → 选择鱼饵(5档) → 选择鱼竿(13种)
        ↓
   自动抛竿(每6秒1杆)
        ↓
   一杆多鱼(力量决定数量) → 判定品质(运气决定稀有度)
        ↓
   结算金币 + 经验(各种加成叠加)
        ↓
   金币 → 解锁地图/强化鱼竿/买鱼饵/买buff
   经验 → 升级(解锁更高地图)
   鱼获 → 出售换金币 / 献祭给专精
```

- 单批次杆数上限 = **耐力 × 2**（耐力越高单轮能钓越久）
- 鱼获自动累积，可**批量出售**换金币（市场或直接卖）
- 高品质鱼（传说/神话/奇异/奥秘）另有**保底与活动**玩法

## 三、品质系统（9 级，核心中的核心）

| 品质 | 概率权重 | 幸运影响 | 经验倍率 |
|---|---|---|---|
| 普通 common | ★★★★★★ | 无 | ×1.05 |
| 罕见 uncommon | ★★★★★ | 极低 | ×1.15 |
| 精良 fine | ★★★★ | 低 | ×1.30 |
| 稀有 rare | ★★★ | 中 | ×1.50 |
| 史诗 epic | ★★ | 中 | ×1.80 |
| 传说 legendary | ★ | 高 | ×2.20 |
| 神话 mythic | ★ | 高 | ×2.80 |
| 奇异 exotic | 极低 | 高 | ×3.60 |
| 奥秘 arcane | 极低 | 极高 | ×5.00 |

- 品质权重越大越容易出；**幸运值按各品质的敏感度放大对应权重**（普通不受幸运影响，所以堆幸运只挤掉普通、放大高阶）
- 实测（13,261 杆）：普通约 35%、罕见 32%、精良 19%、稀有 9%、史诗 4.6%，传说以上合计不到 0.1%——**传说/神话/奇异/奥秘是真正的稀有货**

## 五、天气系统（每 2 小时一轮）

| 天气 | 效果 | 出现权重 |
|---|---|---|
| 晴朗 | 无修正 | 4 |
| 雨幕 | 经验 +5% | 4 |
| 强风 | 经验 +10% | 3 |
| 浓雾 | 经验 +20% | 3 |
| 热浪 | 经验 +30% | 2 |
| 雷暴 | 经验 +50% | 2 |
| 枯潮 | 经验 -50%（第一张图除外） | 1 |
| **金风** | **直接金币区间 +300~500**（第一张图除外） | 1 |
| 奥秘涌流 | 经验 +75%（全服事件触发） | 0 |

- 天气每 2 小时整点切换（如 14:00~16:00）
- **冲级看准热浪/雷暴/浓雾**，**赚钱等金风**（配金风感知天赋收益翻倍）
- 枯潮经验减半，建议换图躲开

## 六、鱼饵系统（5 档）

| 鱼饵 | 单价 | 幸运 | 可钓最高品质 | 特点 |
|---|---|---|---|---|
| 基础饵 | 免费 | 0 | 罕见 | 无限量 |
| 低级饵 | 40 | 0 | 史诗 | 掉遗物 |
| 中级饵 | 100 | +250 | 奥秘 | 掉装备+宝箱 |
| 高级饵 | 200 | +500 | 奥秘 | 神话/奇异/奥秘权重 ×1.25 |
| 顶级饵 | 1000 | +1000 | 奥秘 | 至少罕见；高阶权重 ×1.5 |

- 鱼饵只提供**幸运**和**品质池**，不直接加经验/金币
- 全图共用鱼饵库存，低级饵可自动补充

## 七、鱼竿系统（13 种）

- **单属性竿**（力量/智力/运气/耐力）：每级 +20 属性，最高 500 级
- **双属性竿**（如力量·智力竿）：两属性各半
- **功能竿**：寻珍竿（掉装备）、探匣竿（掉宝箱）
- 强化费用递增：升 1 级约 1.5 万，升 499 级到 500 级要近 6 亿金币
- 玩家实测 349 级力量·智力竿 = 力量 +5235 / 智力 +5235

## 八、四维属性（决定一切加成）

| 属性 | 效果 |
|---|---|
| **力量** | 每杆普通鱼**数量** + 直接金币**下限** |
| **智力** | 经验加成（1:1 转加成） + 直接金币**上限** |
| **运气** | 提高高品质鱼概率（按敏感度放大权重） |
| **耐力** | 单批次**杆数上限**（×2）+ 直接金币**下限** |

属性来源：基础 + 鱼竿 + 装备（8 槽）+ 奖牌 + 公会 + buff。
转换规律：每 150 点智力/耐力 = 直接金币 +5；智力 1 点 = 经验加成 0.01%。

## 九、专精与天赋

- **专精**：每张图 9 个品质各对应一条「专精鱼」，把对应品质的鱼献祭够数量，提升该图专精等级 → 获得经验/金币加成 + **专精点**
- **天赋**：专精点用于点亮 5 个天赋（渊博垂钓者=全图经验、稳定收益=金币上下限、金风感知=金风时金币），详见天赋攻略
- 专精是**滚雪球的加速器**：鱼越多 → 献祭越快 → 加成越高

## 十、公会、组队船与赛事

- **公会**：图腾（经验/幸运/力量/财宝/成员）、区域增益（地图经验 +50%）、税率、公会赛
- **组队船**：1~7 人同船，按人数获得**独立经验乘区**（实测 6 人 +25%）
- **周赛**：个人赛分三组（500 级以下进「新星组」用前四张图），每周一自动分组，奖牌永久提供全属性加成

## 十一、怎么串起来玩（给新手的优先序）

1. **先解锁图**：等级到了就解锁新图（收益倍率 + 专精加成双提升）
2. **再强化鱼竿**：选一条主线属性竿升到 200+ 级，属性收益远超地图
3. **挂机冲级看天气**：热浪/雷暴/浓雾时冲经验，金风时赚钱
4. **鱼饵按需**：缺遗物用低级/中级饵，追求高品质用高级/顶级饵
5. **专精鱼优先献祭**：把当前图各品质专精鱼喂满，换加成和专精点
6. **后期进公会 + 组队船**：公会区域 +50% 经验和组队船 +25% 都是独立乘区
